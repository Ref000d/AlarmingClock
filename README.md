# ⏰ Alarming Clock

A simple Python alarm clock application built with **CustomTkinter**.  
It lets you set an alarm time using a graphical clock and plays a sound when the alarm triggers.

## 🧩 Usage

Run the "AlarmingClock.exe"

## 🔧 Requirements (For developers)

Make sure you have Python 3 installed and these libraries:

```
py -m pip install customtkinter Pillow
```

`pygame` is used for sounds (I know it's awkward, but it is what it is):

```
py -m pip install pygame
```
#### Then:

1. Clone the repository:

```bash
git clone https://github.com/Ref000d/AlarmingClock.git
cd AlarmingClock
```

2. Run the app:

```bash
python main.py
```
Or use vscode/other IDEs to run the file (just run it somehow, okay?).
All codes are inside `main.py`
